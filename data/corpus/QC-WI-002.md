# Northline Precision — QA Work Instruction QC-WI-002

**Title:** In-process first-article inspection  
**Asset:** CNC-07 · **Inspection interval:** first part of every run + after any program change

## §1 Purpose

Confirm the first part conforms before the run is released to production.

## §2 Procedure

1. Measure all drawing dimensions marked critical-to-quality (CTQ).
2. Record the measurements on the FAI sheet and initial it.
3. Release the run only after QA signs the FAI sheet.

## §3 Pass / Fail Criteria

- **PASS:** Every CTQ dimension within its drawing tolerance.
- **FAIL:** Any CTQ out of tolerance — stop the run, adjust the offset, re-cut.

## §4 Tooling

CMM-04, bore gauges, thread gauges
