# Northline Precision — QA Work Instruction QC-WI-005

**Title:** Hole-position tolerance check on the CMM  
**Asset:** CMM-04 · **Inspection interval:** every 25 parts

## §1 Purpose

Verify hole-position tolerance using CMM-04.

## §2 Procedure

1. Qualify the probe on the reference sphere.
2. Measure the datum features first, then the hole axes.
3. Report the true-position deviation against the drawing.

## §3 Pass / Fail Criteria

- **PASS:** True-position deviation within 0.05 mm.
- **FAIL:** Deviation above 0.05 mm — quarantine and raise a non-conformance.

## §4 Tooling

CMM-04 with the Ø2 mm ruby stylus
